## 1. Five Pydantic Output Schemas

All schemas live in `api/schemas/output.py`. Every inference response extends `BaseOutput`.

### BaseOutput — shared by all task types

```python
from pydantic import BaseModel, UUID4
from datetime import datetime

class BaseOutput(BaseModel):
    output_id:          UUID4
    workpaper_id:       UUID4
    chunk_id:           UUID4 | None
    task_type:          str
    output_status:      str                  # always "AI_DRAFT" from API — no exceptions
    model_version:      str
    confidence_score:   float | None         # 0.0–1.0 logit probability of top token
    rag_used:           bool
    processing_time_ms: int | None
    hallucination_flag: bool = False         # TRUE if any citation was removed by post-processor
    opinion_flag:       bool = False         # TRUE if opinion language was detected and removed
    missing_fields:     list[str] = []       # fields that were absent and retried
    created_at:         datetime
    reviewer_id:        UUID4 | None = None
    reviewed_at:        datetime | None = None
    ai_draft_label:     str = "AI-Assisted Draft — Requires Senior Auditor Review Before Use"
```

## 2. Export Renderer

### 2.1 Format Resolution

```python
# api/routers/outputs.py

def resolve_export_format(
    query_format: str | None,
    engagement: Engagement,
    workpaper: Workpaper,
    output: BaseOutput,
) -> str:
    # NER is Excel-only — word/pdf/caseware are not supported
    if output.task_type == 'ner_extraction':
        if query_format in ('word', 'pdf', 'caseware'):
            raise HTTPException(
                status_code=400,
                detail="NER extraction outputs only support format=excel"
            )
        return 'excel'

    # 1. Per-download override
    if query_format in ('word', 'excel', 'pdf', 'caseware'):
        return query_format

    # 2. Engagement default
    if engagement.default_export_format:
        return engagement.default_export_format

    # 3. Hardcoded defaults by workpaper_type
    if workpaper.workpaper_type == 'trial_balance':
        return 'excel'

    # 4. Fallback for all other types
    return 'word'
```

### 2.3 Word Renderer

**Known issue with python-docx placeholder splitting:** When a Word template is created with autocorrect or spell-check active, placeholder text such as `{{FINDING_TITLE}}` may be split across multiple XML `<w:r>` runs (e.g., `{{`, `FINDING`, `_TITLE`, `}}`). `para.text` returns the concatenated string correctly, so `if key in para.text` passes — but assigning `para.text = ...` only writes to the first run, leaving orphaned run fragments. This causes partial placeholder text to appear in the exported document.

**Fix: run merger applied before every replacement.** `merge_runs()` consolidates all runs in a paragraph into a single run, preserving the full text. Applied to both body paragraphs and table cell paragraphs before the replacement loop.

```python
# export/word_renderer.py

from docx import Document
from docx.oxml.ns import qn
from docx.shared import Pt, RGBColor
from pathlib import Path


def merge_runs(para) -> None:
    """Consolidate all runs in a paragraph into the first run.

    Prevents partial placeholder replacement when Word split the placeholder
    text across multiple <w:r> elements during template authoring.
    """
    if len(para.runs) <= 1:
        return
    full_text = "".join(run.text for run in para.runs)
    para.runs[0].text = full_text
    for run in para.runs[1:]:
        run.text = ""


def _replace_in_para(para, replacements: dict) -> None:
    merge_runs(para)
    for key, value in replacements.items():
        if key in para.text:
            para.runs[0].text = para.runs[0].text.replace(key, str(value))


def render_word(output: BaseOutput, template_name: str) -> bytes:
    template_path = Path('templates') / template_name
    doc = Document(str(template_path))

    replacements = build_replacements(output)

    for para in doc.paragraphs:
        _replace_in_para(para, replacements)

    for table in doc.tables:
        for row in table.rows:
            for cell in row.cells:
                for para in cell.paragraphs:
                    _replace_in_para(para, replacements)

    # Always inject AI draft watermark before first paragraph
    watermark = doc.paragraphs[0].insert_paragraph_before(
        "AI-ASSISTED DRAFT — NOT FOR FINAL WORKPAPER USE WITHOUT SENIOR AUDITOR REVIEW"
    )
    watermark.runs[0].font.color.rgb = RGBColor(0xFF, 0x00, 0x00)
    watermark.runs[0].font.size = Pt(9)

    import io
    buffer = io.BytesIO()
    doc.save(buffer)
    return buffer.getvalue()
```

**What changed vs. the naive implementation:**
- `merge_runs()` collapses multi-run paragraphs into one before any replacement — eliminates orphaned run fragments
- Replacement now targets `para.runs[0].text` directly (never `para.text =`) — preserves run-level formatting (bold, italic, font size) on surrounding text
- Table cell iteration changed from `cell.text` to `cell.paragraphs` — cells can contain multiple paragraphs, each of which may contain split runs
- `build_replacements()` values cast to `str(value)` to prevent type errors on numeric fields (e.g., `anomaly_score`)

### 2.4 Excel Renderer

```python
import io, re
from openpyxl import load_workbook

def render_excel(output: BaseOutput, template_name: str) -> bytes:
    template_path = Path('templates') / template_name
    wb = load_workbook(str(template_path))
    ws = wb.active

    replacements = build_replacements(output)

    for row in ws.iter_rows():
        for cell in row:
            if cell.value and isinstance(cell.value, str):
                for key, value in replacements.items():
                    if key in cell.value:
                        cell.value = cell.value.replace(key, value)

    # Clear any unreplaced {{PLACEHOLDER}} tokens left by the generic template.
    # These arise when the template contains placeholders for all output types but
    # build_replacements() only populates keys relevant to the current output type.
    _PLACEHOLDER_RE = re.compile(r'\{\{[A-Z_]+\}\}')
    for row in ws.iter_rows():
        for cell in row:
            if cell.value and isinstance(cell.value, str) and _PLACEHOLDER_RE.search(cell.value):
                cell.value = ''

    buffer = io.BytesIO()
    wb.save(buffer)
    return buffer.getvalue()
```

#### generic_excel_v1.xlsx — Template Layout

`templates/generic_excel_v1.xlsx` is the fallback Excel template for any output type not matched by a more specific template. It contains a single sheet — **"AI Draft Output"** — with two columns: Label (A) and Value (B). Column B cells hold `{{PLACEHOLDER}}` tokens; the renderer replaces matched tokens and blanks out the rest.

| Row | Column A — Label | Column B — Placeholder | Populated by |
|-----|-----------------|------------------------|-------------|
| 1 | **Label** *(bold header)* | **Value** *(bold header)* | — |
| 2 | AI Draft Notice | `{{AI_DRAFT_LABEL}}` | all types |
| 3 | Output ID | `{{OUTPUT_ID}}` | all types |
| 4 | Task Type | `{{TASK_TYPE}}` | all types |
| 5 | Model Version | `{{MODEL_VERSION}}` | all types |
| 6 | Created At | `{{CREATED_AT}}` | all types |
| 7 | *(blank separator)* | | |
| 8 | Risk Level | `{{RISK_LEVEL}}` | risk_classification, finding_documentation |
| 9 | Risk Factors | `{{RISK_FACTORS}}` | risk_classification |
| 10 | Criteria | `{{CRITERIA}}` | finding_documentation |
| 11 | Condition | `{{CONDITION}}` | finding_documentation |
| 12 | Cause | `{{CAUSE}}` | finding_documentation |
| 13 | Effect | `{{EFFECT}}` | finding_documentation |
| 14 | Compliant | `{{COMPLIANT}}` | compliance_check |
| 15 | Violations | `{{VIOLATIONS}}` | compliance_check |
| 16 | Thresholds Triggered | `{{THRESHOLDS_TRIGGERED}}` | compliance_check |
| 17 | Summary | `{{SUMMARY}}` | summarization |
| 18 | Key Figures | `{{KEY_FIGURES}}` | summarization |
| 19 | Flagged Items | `{{FLAGGED_ITEMS}}` | summarization |
| 20 | *(blank separator)* | | |

**Column widths:** A = 28, B = 80 (wrap text enabled on column B).  
**Rows 8–22 that receive no replacement** are blanked by the cleanup pass — the label in column A remains, the value in column B becomes empty. This is intentional: the label rows act as visual structure and a blank value signals the auditor that this field does not apply to the current output type.

### 2.5 PDF Renderer

```python
import subprocess
import tempfile

def render_pdf(output: BaseOutput, template_name: str) -> bytes:
    # Render to Word first, then convert via LibreOffice headless
    word_bytes = render_word(output, template_name)

    with tempfile.TemporaryDirectory() as tmpdir:
        docx_path = Path(tmpdir) / 'output.docx'
        docx_path.write_bytes(word_bytes)

        subprocess.run([
            'libreoffice', '--headless', '--convert-to', 'pdf',
            '--outdir', tmpdir,
            str(docx_path),
        ], check=True, timeout=30)

        pdf_path = Path(tmpdir) / 'output.pdf'
        return pdf_path.read_bytes()
```

### 2.6 Replacement Map Builder

```python
def build_replacements(output: BaseOutput) -> dict[str, str]:
    base = {
        '{{OUTPUT_ID}}':      str(output.output_id),
        '{{TASK_TYPE}}':      output.task_type,
        '{{MODEL_VERSION}}':  output.model_version,
        '{{CREATED_AT}}':     output.created_at.strftime('%Y-%m-%d %H:%M'),
        '{{AI_DRAFT_LABEL}}': output.ai_draft_label,
    }

    if isinstance(output, RiskClassificationOutput):
        base.update({
            '{{RISK_LEVEL}}':       output.risk_level,
            '{{RISK_FACTORS}}':     '\n'.join(f'• {f}' for f in output.risk_factors),
            '{{REGULATION}}':       ', '.join(output.regulation_cited),
            '{{RECOMMENDATION}}':   output.recommendation or '',
        })

    elif isinstance(output, FindingDocumentationOutput):
        base.update({
            '{{CRITERIA}}':         output.criteria or '',
            '{{CONDITION}}':        output.condition or '',
            '{{CAUSE}}':            output.cause or '',
            '{{EFFECT}}':           output.effect or '',
            '{{RECOMMENDATION}}':   output.recommendation,
            '{{RISK_LEVEL}}':       output.risk_level or '',
            '{{REGULATION}}':       ', '.join(output.regulation_cited),
        })

    elif isinstance(output, ComplianceCheckOutput):
        violations_text = '\n'.join(
            f'• {v.regulation_id}: {v.description} [{v.severity}]'
            for v in output.violations
        ) or 'None identified'

        thresholds_text = '\n'.join(
            f'• {t.threshold_name}: {t.currency} {t.value_found:,.2f}'
            f' (limit: {t.currency} {t.limit:,.2f})'
            f' — {"EXCEEDED" if t.exceeded else "within limit"}'
            for t in output.thresholds_triggered
        ) or 'No thresholds evaluated for this workpaper type'

        base.update({
            '{{COMPLIANT}}':             'YES' if output.compliant else 'NO',
            '{{VIOLATIONS}}':            violations_text,
            '{{THRESHOLDS_TRIGGERED}}':  thresholds_text,
            '{{REGULATION}}':            ', '.join(output.regulation_cited),
            '{{RECOMMENDATION}}':        output.recommendation or 'No action required',
        })

    elif isinstance(output, SummarizationOutput):
        figures_text = '\n'.join(
            f'• {f.label}: {f.value} {f.currency}'
            for f in output.key_figures
        )
        base.update({
            '{{SUMMARY}}':          output.summary,
            '{{KEY_FIGURES}}':      figures_text,
            '{{FLAGGED_ITEMS}}':    '\n'.join(f'• {i}' for i in output.flagged_items),
            '{{WORKPAPER_TYPE}}':   output.workpaper_type or '',
        })

    return base
```

### 2.7 API Error Response Contract

All workpaper-scoped endpoints enforce `workpaper_permissions` RBAC. The following error responses are standardised across all output and export routes:

| HTTP Status | When | Response body |
|-------------|------|---------------|
| `200 OK` | Success | Output schema or file bytes |
| `403 Forbidden` | User has no `workpaper_permissions` row for this workpaper, **or** the row exists but grants insufficient permission for the operation | `{"detail": "Insufficient permissions for this workpaper"}` — intentionally identical for "not found" and "forbidden" to prevent workpaper enumeration |
| `404 Not Found` | Output or workpaper does not exist in DB (used only for resources the user is already known to have access to, e.g. `/outputs/{id}` after `/workpapers/{id}/outputs` returned the id) | `{"detail": "Not found"}` |
| `409 Conflict` | Workpaper already being processed (Redis lock held) | `{"detail": "Workpaper currently being processed — retry in 60s"}` |
| `422 Unprocessable Entity` | Validation failure (invalid enum value, missing required field, `financial_context` empty when required) | Standard FastAPI ValidationError body |

**Implementation:** `require_wp_permission(level: wp_permission)` is a FastAPI dependency injected into each route:

```python
# api/dependencies.py

async def require_wp_permission(
    workpaper_id: UUID,
    level: wp_permission,
    current_user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> None:
    row = await db.execute(
        select(WorkpaperPermission).where(
            WorkpaperPermission.workpaper_id == workpaper_id,
            or_(
                WorkpaperPermission.user_id == current_user.id,
                WorkpaperPermission.role == current_user.role,
            ),
        ).order_by(WorkpaperPermission.permission.desc())  # highest permission first
    )
    grant = row.scalar_one_or_none()
    if grant is None or PERMISSION_RANK[grant.permission] < PERMISSION_RANK[level]:
        raise HTTPException(status_code=403, detail="Insufficient permissions for this workpaper")

PERMISSION_RANK = {"read": 1, "write": 2, "review": 3, "approve": 4}
```

### 2.8 Caseware Exporter (.cwx)

**Scope:** Phase 1 — generates a `.cwx` XML import file the auditor manually imports into Caseware Working Papers via `File → Import → Working Paper Exchange`. No Caseware API credentials required. Phase 2 (post-go-live) will add direct push to Caseware Cloud API.

**Supported output types:** `FindingDocumentationOutput`, `RiskClassificationOutput`, `ComplianceCheckOutput`. Summarization and NER outputs do not map to Caseware working paper types and return HTTP 400 if `?format=caseware` is requested for them.

**CWX file structure:**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<CasewareExchange version="1.0" xmlns="urn:caseware:exchange:v1">
  <Header>
    <ExportedBy>Audit AI v{model_version}</ExportedBy>
    <ExportedAt>{iso_timestamp}</ExportedAt>
    <EngagementCode>{engagement_code}</EngagementCode>
    <AILabel>AI-ASSISTED DRAFT — NOT FOR FINAL USE WITHOUT SENIOR AUDITOR REVIEW</AILabel>
  </Header>
  <WorkingPapers>
    <WorkingPaper>
      <Ref>{workpaper_ref}</Ref>
      <Type>Finding</Type>              <!-- Finding | RiskAssessment | ComplianceTest -->
      <RiskLevel>{risk_level}</RiskLevel>
      <Criteria>{criteria}</Criteria>
      <Condition>{condition}</Condition>
      <Cause>{cause}</Cause>
      <Effect>{effect}</Effect>
      <Recommendation>{recommendation}</Recommendation>
      <RegulationsCited>
        <Regulation>{reg_1}</Regulation>
        <Regulation>{reg_2}</Regulation>
      </RegulationsCited>
      <ConfidenceScore>{confidence_score}</ConfidenceScore>
      <OutputId>{output_id}</OutputId>  <!-- traceability back to Audit AI DB -->
    </WorkingPaper>
  </WorkingPapers>
</CasewareExchange>
```

**Implementation:**

```python
# export/caseware_exporter.py

from xml.etree.ElementTree import Element, SubElement, tostring
from xml.dom import minidom
from datetime import datetime, timezone


def render_caseware(output: BaseOutput, engagement_code: str, workpaper_ref: str) -> bytes:
    if not isinstance(output, (FindingDocumentationOutput,
                               RiskClassificationOutput,
                               ComplianceCheckOutput)):
        raise ValueError(f"caseware export not supported for {output.task_type}")

    root = Element("CasewareExchange",
                   version="1.0",
                   xmlns="urn:caseware:exchange:v1")

    hdr = SubElement(root, "Header")
    SubElement(hdr, "ExportedBy").text   = f"Audit AI v{output.model_version}"
    SubElement(hdr, "ExportedAt").text   = datetime.now(timezone.utc).isoformat()
    SubElement(hdr, "EngagementCode").text = engagement_code
    SubElement(hdr, "AILabel").text      = output.ai_draft_label

    wps = SubElement(root, "WorkingPapers")
    wp  = SubElement(wps, "WorkingPaper")

    SubElement(wp, "Ref").text        = workpaper_ref
    SubElement(wp, "Type").text       = _cwx_type(output.task_type)
    SubElement(wp, "RiskLevel").text  = output.risk_level or "N_A"
    SubElement(wp, "OutputId").text   = str(output.output_id)
    SubElement(wp, "ConfidenceScore").text = str(round(output.confidence_score or 0.0, 4))

    if isinstance(output, FindingDocumentationOutput):
        SubElement(wp, "Criteria").text       = output.criteria or ""
        SubElement(wp, "Condition").text      = output.condition or ""
        SubElement(wp, "Cause").text          = output.cause or ""
        SubElement(wp, "Effect").text         = output.effect or ""
        SubElement(wp, "Recommendation").text = output.recommendation

    regs = SubElement(wp, "RegulationsCited")
    for reg in output.regulation_cited:
        SubElement(regs, "Regulation").text = reg

    # Pretty-print for readability in Caseware
    raw = tostring(root, encoding="unicode")
    pretty = minidom.parseString(raw).toprettyxml(indent="  ", encoding="UTF-8")
    return pretty


def _cwx_type(task_type: str) -> str:
    return {
        "finding_documentation": "Finding",
        "risk_classification":   "RiskAssessment",
        "compliance_check":      "ComplianceTest",
    }[task_type]
```

**Response headers for `.cwx` download:**

```
Content-Type: application/xml
Content-Disposition: attachment; filename="{engagement_code}_{workpaper_ref}_audit_ai.cwx"
```

**Phase 2 note:** Caseware Cloud exposes a REST API (`/api/v2/workingpapers`). When the firm upgrades to Caseware Cloud, the `render_caseware()` function is replaced with a direct `POST` using the firm's Caseware API token (stored in `Settings.caseware_api_token`, vault-managed). The `.cwx` download path remains as a fallback.

### 2.9 NER Excel Renderer

NER outputs do not use template replacement — the entity list is variable-length and cannot be expressed as a fixed template. `render_ner_excel()` builds the workbook from scratch using openpyxl directly. No template file needed.

**Workbook structure:** two sheets — `Summary` (metadata + PII alert) and `Entities` (one row per extracted entity).

```python
# export/excel_renderer.py

from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.utils import get_column_letter
import io


def render_ner_excel(output: NERExtractionOutput) -> bytes:
    wb = Workbook()

    # --- Sheet 1: Summary ---
    ws_sum = wb.active
    ws_sum.title = "Summary"

    summary_rows = [
        ["Field",              "Value"],
        ["Output ID",          str(output.output_id)],
        ["Model Version",      output.model_version],
        ["Exported At",        output.created_at.strftime("%Y-%m-%d %H:%M UTC")],
        ["Total Entities",     len(output.entities)],
        ["Entity Types Found", ", ".join(output.entity_types_found)],
        ["PII Detected",       "YES — PIPELINE ALERT" if output.pii_detected else "No"],
        ["AI Label",           output.ai_draft_label],
    ]
    for row in summary_rows:
        ws_sum.append(row)

    # Bold header row
    for cell in ws_sum[1]:
        cell.font = Font(bold=True)

    # Red PII row if triggered
    if output.pii_detected:
        pii_row_idx = next(
            i for i, r in enumerate(summary_rows, 1) if r[0] == "PII Detected"
        )
        ws_sum.cell(row=pii_row_idx, column=2).font = Font(bold=True, color="FF0000")

    # --- Sheet 2: Entities ---
    ws_ent = wb.create_sheet("Entities")

    headers = ["#", "Entity Type", "Extracted Value", "Confidence", "Source Location", "PII Flag"]
    ws_ent.append(headers)

    # Dark-blue header styling
    header_fill = PatternFill(start_color="1F4E79", end_color="1F4E79", fill_type="solid")
    for cell in ws_ent[1]:
        cell.font      = Font(bold=True, color="FFFFFF")
        cell.fill      = header_fill
        cell.alignment = Alignment(horizontal="center")

    for idx, entity in enumerate(output.entities, start=1):
        is_pii = entity.entity_type in output.pii_types
        ws_ent.append([
            idx,
            entity.entity_type,
            entity.value,
            f"{round(entity.confidence * 100, 1)}%",
            entity.position or "",
            "⚠ PII" if is_pii else "",
        ])
        if is_pii:
            for cell in ws_ent[ws_ent.max_row]:
                cell.font = Font(color="FF0000")

    # Auto-fit column widths (cap at 60)
    for ws in (ws_sum, ws_ent):
        for col in ws.columns:
            col_width = max(len(str(cell.value or "")) for cell in col)
            ws.column_dimensions[get_column_letter(col[0].column)].width = min(col_width + 4, 60)

    buffer = io.BytesIO()
    wb.save(buffer)
    return buffer.getvalue()
```

**Response headers:**

```
Content-Disposition: attachment; filename="{engagement_code}_{workpaper_ref}_ner.xlsx"
```

**PII alert behaviour:** If `output.pii_detected == True`, the Summary sheet's PII row is rendered in red bold. The API also fires an admin alert (same path as the pipeline PII detection alert) so the data engineer is notified even if the auditor downloads the file without reading it carefully.

**Maintenance:** Updated annually by admin role. After update, all active model versions re-validated against new master list.

### Validation behaviour at inference

At inference time, `post_processor.py` loads the file once at module import and verifies every `regulation_cited` value against it. The check is implemented in `05_rag_inference.md` — Section 9 Step 3.

**Fiscal-year filter:** A regulation whose `effective_from` date falls *after* the engagement's `fiscal_year` end (December 31 of that year) is treated as not yet in effect and is excluded from the valid set for that engagement. Example: `AU-C 315` with `effective_from: 2022-12-15` is valid for fiscal year 2023+ but not for a fiscal year 2021 engagement.

**On citation failure (ID not in valid set for the engagement's fiscal year):**
1. The failing ID is removed from `regulation_cited` in the output object
2. `hallucination_flag` is set to `True` on the `BaseOutput`
3. The removed ID is logged to MLflow under `hallucinated_citations`
4. The output is still surfaced as `AI_DRAFT` — the reviewer sees a `⚠️ Unverified citation removed` banner
5. The `hallucination_after` counter in `training_runs` increments — tracked for model quality monitoring

**Adding a new regulation:** Add a new top-level key to `regulations_master.json` using the same schema as existing entries. The key is the exact citation string the model is expected to produce (e.g., `"2 CFR 200.518"` — not a shortened alias). Restart the API server so the module-level load picks up the change.
